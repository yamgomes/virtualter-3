# Protótipos anteriores

Esta pasta preserva os modos de jogo e gerenciadores anteriores à arquitetura ativa.
Não é importada pelo ponto de entrada, nem incluída no build TypeScript.
`MODULAR_SYSTEM.md` documenta apenas esses protótipos históricos.

O surfe ativo fica em `src/games/surfing/` na raiz do projeto. Os placeholders antigos
de natação, surfe e sentar/levantar não devem ser registrados como jogos disponíveis.

A migração preserva os arquivos existentes; o filtro One Euro continua compartilhado
com o código ativo. Consulte `../CLIENTE_JOGADOR.md` para desenvolver novos jogos.
